# Dayflow 产品需求 V0.1

## 定位
日程为底座，执行与习惯养成为核心，训练只是一个可扩展的任务类别。

## 业务名词
- TimeBlock: 固定占用 fixed、并行待办 parallel、顺序执行 sequence。
- Task: 可独立完成的事项；sequence 下的 action 也是可打卡的最小执行单位。
- ScheduleTemplate: 以星期几和当地钟点描述的重复安排。
- DailyInstance: 某一天按模板生成的计划快照（未来版本）。
- Record: 某日某任务的完成状态和用户输入，永不因为模板改动被覆盖。

## 功能范围
M1: 七日导航、日期定位、时间轴、并行折叠、顺序动作、任务勾选、昨日复盘、本地统计。
M2: 任务状态细化（跳过/延期/停止）、日期切换中的提醒和恢复。
M3: 可视化编辑、导入校验、云端用户隔离、照片打卡、版本化计划。
M4: 统计图、15 分钟降级方案、经审核的阶段进阶。
M5: 微信订阅提醒可行性、外链与视频合规、安卓 iOS 真机兼容与上线。

## 关键验收
1. 任何日期默认显示所在周周一至周日；今天默认选中。
2. 固定占用仅展示，不参与完成率计算。
3. 并行任务独立勾选；顺序训练每个动作独立勾选。
4. 相同星期不同自然日期的完成状态互不干扰。
5. 用户更改模板不能更改已有历史记录（M3 完成）。
6. 本地日期转换不能受 UTC 日期边界影响。
7. 今天首次进入读取昨天的记录，且每天最多弹一次；无昨日数据不弹。
8. 危险信号与中止应始终可用；演示运动数据不构成医疗建议。

## 公开数据约束
禁止将用户个人病历、医疗术后详情、私人照片与访谈信息写入公开仓库。

| 编号 | 验收标准 | 当前证据 |
| --- | --- | --- |
| M1-VERIFY-001 | 今日页保持前台时，分钟变化后更新当前/下一时间块；隐藏和卸载清理时钟 | Node 生命周期测试通过，模拟器待验证 |
| M1-VERIFY-002 | 前台或后台跨午夜，仅在原先查看今天时跟随新一天；手选其他日期不变 | Node 页面测试通过，模拟器待验证 |
| M1-VERIFY-003 | 训练详情拒绝不存在的日历日期，不崩溃、不写入错误日期记录 | Node 页面和模板测试通过，模拟器待验证 |
| M1-VERIFY-004 | 存储读取失败或数据损坏时停止写入，保留历史；写入失败不宣告完成 | 故障注入复现后修复，Node 测试通过 |
| M1-QA-001 | 可重复执行编译、导航、独立勾选与日志采集，并恢复测试前记录 | PowerShell 脚本与契约测试通过，需实际模拟器验收 |
