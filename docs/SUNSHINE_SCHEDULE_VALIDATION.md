日期：2026-10-31。需求与边界见 [SUNSHINE_SCHEDULE_CONTRACT.md](SUNSHINE_SCHEDULE_CONTRACT.md)。前轮的244项测试、390px的337条断言和320px的210条断言只作为历史记录，不能当作本轮通过证据。

## 重复入口

业务源冻结并通过 `npm run typecheck`、`npm test` 后，由具备本机桌面权限的普通 Windows PowerShell 执行：

```powershell
pwsh -NoProfile -File scripts/wechat-planning-wizard.ps1 -Mode Sunshine -Label default
pwsh -NoProfile -File scripts/wechat-planning-wizard.ps1 -Mode Sunshine -Label narrow
```

第一条要求实际窗口宽390px，第二条要求320px。标签不会修改模拟机型，必须先在开发者工具中选择实际设备。旧 `Validate`、`Layout`、`Restore`、`Poll` 入口保留；本轮仅使用新的 `Sunshine` 流程收集结果。

脚本复用已有登录/版本门禁、令牌要求、UTF-8解码、原生参数数组及挂起任务保护。只使用合成中文数据；先备份全部 `dayflow.*` 值与存在性，结束或非挂起失败时还原API、双恢复本地存储并精确读回。恢复检查未完成不能启动新验收或切换设备。原日志、截图、源码SHA-256清单和备份仅保留在忽略的本地 `artifacts/wechat-planning-wizard`，不提交公开仓库。

## 本轮核心场景

| 场景 | 验收标准 |
| --- | --- |
| 午夜结束与起点 | 通过实际多列组件候选选择23:00–24:00，结束24:00仅允许00分；开始列表没有24:00。最终保存和重读值准确，旧记录和锁定历史不变。 |
| 当前星期重复 | 日期选择未来周三，直接选择“每周三”；日期改周四后对应“每周四”。工作日是周一至五，非工作日是周六日，每天覆盖七天，不假定法定节假日调休。 |
| 新版例子只读预览 | v3例子每周二、四、六无加班，17:30–19:00预留游泳；周一、三、五、日17:00–20:00加班、回家后20:30–22:00预留训练；每天22:00–23:00准备、00:00–08:00与23:00–24:00精确睡眠占用。预览不改当前计划和执行事实。 |
| 已存自定义计划采用作息 | 合成旧v2夜间、已存版本4、自定义08:00–12:00白天工作和独立午间阅读，通过“更新晚间作息”预览、取消零写；一次确认只新增一个版本，未来七日应用新夜间节奏，同时白天、兴趣、已完成的今天及历史快照不变。该路径不使用全模板导入。 |
| 实际睡眠占用 | 今日页面真实显示两个睡眠分段；离线真实服务证明05:00已占用、08:00边界可衔接。外部占用可按既有显式确认流程替换，不能静默删除。 |
| 五页视觉 | 今日、计划、统计、我的、训练详情均由实际小程序页面导航和截图验证；暖底/橙色动作/语义类别色、CSS细线图标、长名称换行与主要44px触区无横向挤压；小屏允许纵向滚动。 |
| 原有核心能力回归 | 390px保留跨工作日的一次确认覆盖；两宽均验证今日休息的理由、停止进行中任务、保留完成记录、暂停计时和恢复不自动重启。 |

预留90分钟不等于强制增加运动强度；新模板保留原动作剂量，额外时间用于自主准备、休息和记录。旧v1/v2历史、无快照旧记录及已有自定义模板的兼容由独立服务/模板测试验证。
