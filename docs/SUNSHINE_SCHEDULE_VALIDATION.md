## 重复入口

业务源冻结并通过 `npm run typecheck`、`npm test` 后，由具备本机桌面权限的普通 Windows PowerShell 执行：

```powershell
pwsh -NoProfile -File scripts/wechat-planning-wizard.ps1 -Mode Sunshine -Label default
pwsh -NoProfile -File scripts/wechat-planning-wizard.ps1 -Mode Sunshine -Label narrow
```

第一条要求实际窗口宽390px，第二条要求320px。标签不会修改模拟机型，必须先在开发者工具中选择实际设备。旧 `Validate`、`Layout`、`Restore`、`Poll` 入口保留；本轮仅使用新的 `Sunshine` 流程收集结果。

脚本复用已有登录/版本门禁、令牌要求、UTF-8解码、原生参数数组及挂起任务保护。只使用合成中文数据；先备份全部 `dayflow.*` 值与存在性，结束或非挂起失败时还原API、双恢复本地存储并精确读回。恢复检查未完成不能启动新验收或切换设备。原日志、截图、源码SHA-256清单和备份仅保留在忽略的本地 `artifacts/wechat-planning-wizard`，不提交公开仓库。
