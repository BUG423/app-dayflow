# 日常使用简化契约

本轮解决首页信息重复、入口分散、普通计划四步填写和训练页操作堆叠的问题。范围是页面组织与交互，沿用现有计划、实例、执行记录和安全保护。

| 编号 | 需求与验收 |
| --- | --- |
| LEAN-01 | 主导航为今日、计划、我的。执行记录从我的进入独立记录页；记录仍可查看、筛选和展开原始事件。 |
| LEAN-02 | 今日优先展示七日日期、当前安排和时间轴。固定占用紧凑显示，移除重复完成率、类别和待开始标签。休息入口在日程末尾，休息生效时仍显著可见。 |
| LEAN-03 | 昨日复盘为按需打开的入口，进入今日不自动弹窗。打开后仍使用原有完成率口径，不改写执行事实。 |
| LEAN-04 | 普通安排两步完成：事项与时间、重复与保存。首步能同时填写名称、日期、开始和结束；第二步选择重复后保存，已有冲突仍明确列出被替换安排并由用户确认。复用既有校验、租约和历史保护。 |
| LEAN-05 | 计划列表以名称、时间、重复范围为主。导入、版本、训练总览和示例等低频操作集中在底部更多入口；不删除已有复杂安排或重建模板。 |
| LEAN-06 | 我的主入口为记录、提醒、数据备份，训练阶段和关于说明收纳至其他设置。未配置的云服务不展示待开通操作；恢复异常必须自动显露恢复入口，保持拒写保护。 |
| LEAN-07 | 记录页默认为本周完成摘要和每日记录，历史日期筛选与逐条事件按需展开；所有原始记录和筛选能力仍可到达。 |
| LEAN-08 | 训练/步骤详情默认展示名称、时段、次数、必要安全提示和完成勾选。说明、计时、感受、照片通过单项展开呈现；正在运行的计时、休息状态、不适提示和停止入口保持可见。 |
| LEAN-09 | 固定文案使用中文，保留暖色视觉。主要操作至少44px，窄屏长文本可换行，不以缩小字体或横向溢出换取紧凑。 |
| QA-LEAN | 新交互有页面行为回归；运行类型检查和全量单元测试。旧四步脚本与四Tab导航不能当作新版本模拟器验收，按实际环境分别记录本轮模拟器、云和真机状态。 |

## 数据边界

不修改 TimeBlock/Task/Action/Record/Schedule 的存储格式，不迁移或清空用户数据，不改变既有作息、休息和完成率。减少界面入口不代表删除其能力；覆盖、删除、恢复和云同步仍保留原有明确确认与失败保护。

## 验证范围

本轮行为测试使用合成数据。历史346项测试及390px备份专项126条断言是旧版本证据；本轮结果单独记录在 `SIMPLIFICATION_VALIDATION.md`，不得沿用为新界面已验证。
