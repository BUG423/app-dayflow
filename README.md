# Dayflow · 日程流

以时间为入口、以行动为核心的微信原生小程序（TypeScript）。

## 当前版本 M1

- 周一至周日自动定位当天；支持上一周、下一周与指定日期切换
- 今日时间轴：固定占用 / 并行任务 / 顺序训练
- 自动识别当前和下一时间块，支持折叠展开
- 吉他与声乐独立勾选；训练动作逐项打卡
- 本地保存完成状态，昨日复盘，周度完成情况
- 内置七日**示例**日程；工作时间和训练动作数据不代表医学建议

> 当前仅使用微信本地存储。云端身份隔离、照片打卡、批量导入、时间编辑、订阅提醒、阶段解锁将在后续里程碑开发。未接入微信云环境，不会上传任何个人数据。

## 启动

1. 在 Windows 安装微信开发者工具和 Node.js。
2. 克隆仓库，在微信开发者工具中**导入项目**（选择仓库根目录，含 project.config.json）。
3. 将 project.config.json 的占位 appid 改为你自己的小程序 AppID；不要将个人本地配置提交进仓库。也可通过 project.private.config.json 在本机配置。
4. 工具设置启用 TypeScript 编译插件；本项目 project.config.json 已配置 useCompilerPlugins。
5. 在项目根目录执行 npm ci、npm run typecheck、npm test。
6. 点击微信开发者工具「编译」，在模拟器内打开「今日」。

## 工程目录

- miniprogram/pages：今日、计划、训练详情、统计、我的
- miniprogram/data：可编辑的演示周计划
- miniprogram/utils：日期与完成率的纯逻辑
- miniprogram/services：本地执行记录
- tests：Node 内置测试框架单元测试
- docs：产品需求和架构约定

## 隐私及安全

公开仓库仅包括泛化的计划示例，不包括个人医疗情况、用户记录、照片、凭证、AppSecret、云环境密钥。涉及动作强度的示例必须由使用者按实际情况咨询专业人员后使用；用户可跳过或停止任务。请勿把该模板宣传为康复处方。
